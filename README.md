## About

PHANTOM is a CLI-first Python application designed to analyze digital footprints using publicly available information from permitted sources.

The project aims to help users understand their online exposure, identify potential privacy risks, and receive AI-assisted recommendations.

PHANTOM is being developed with a modular architecture, allowing future integration with REST APIs and other interfaces.

## Features

### Implemented

- FastAPI application foundation
- Health check endpoint (`GET /health`)
- Environment-based configuration with Pydantic Settings
- Development tooling with Ruff and pytest

### Planned

- Interactive terminal interface with Typer and Rich
- Full Scan across supported data sources
- Custom Scan with selectable providers
- Public API integrations
- Scan history stored in MongoDB
- Local AI analysis powered by Ollama
- Privacy risk assessment and recommendations
- Automated testing and Docker support

## Installation

### Prerequisites

- Python 3.14
- uv
- Git

Clone the repository:

```bash
git clone https://github.com/moonray69/phantom.git
cd phantom
```

Install dependencies:

```bash
uv sync
```

Create a local environment file:

```bash
cp .env.example .env
```

## Running

The FastAPI foundation is currently available for development.

Start the development server:

```bash
uv run uvicorn app.main:app --reload
```

Available endpoints:

- `GET /` — root endpoint
- `GET /health` — application health check
- `GET /docs` — interactive API documentation

The standalone CLI is under development.

## Privacy & Responsible Use

PHANTOM is intended for authorized privacy assessments and analysis of publicly accessible information.

The application will use permitted data sources and respect provider restrictions. It is not intended for unauthorized access, credential harvesting, or bypassing privacy protections.
